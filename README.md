# IME-клавиатура для конланга хуавэнь (искусственный диалект китайского)

## Назначение
Это IME-клавиатура для моего конланга (искусственного языка). Она работает так же, как и все азиатские клавиатуры, — вы вводите латиницей слог, а она выдаёт вам варианты иероглифов и слов.

Язык называется **бэйтайский** (самоназвание: 北華, *beihua* / *bei hua*), также известен как **хуавэнь** (华文). Это «немного японизированный» диалект китайского, находящийся на стыке китайского и японского. Письменность — иероглифы и чжуинь фухао (注音符號, фонетические значки). Тонов в языке нет — омонимия разрешается контекстом.

## Достоинства
Это простая HTML-страничка, потому у такой клавиатуры есть плюсы:
- Можно запустить на любом устройстве (браузер всё-таки есть почти везде)
- Поддерживаются иероглифы стандарта конланга Huawen-1.1 (H-1.1)
- Легко добавлять свои иероглифы и в принципе перенастраивать систему на любой другой язык (достаточно покопаться в `mappingVariants`)
- Можно по нажатию кнопки получать звучание введённого в поле ввода текста

## Недостатки
Однако интерфейс не идеален, потому есть и минусы:
- Система не рассчитана на большие тексты (строчка с копирайтом будет под фонетической записью)
- Интерфейс весь на хуавэнь, потому вам придётся методом проб и ошибок разбираться в программе (или выучить мой конланг :D)

## Установка и запуск
1. Просто скачайте всё в одну папку и откройте `huawen.html` через любой браузер
2. Наслаждайтесь бесполезностью программы и конланга

## Примечание
Возможно, раздел релизов не пуст, и вы сможете использовать EXE-формат приложения (правда, возникает вопрос «Зачем?»)

## Как пользоваться клавиатурой

### Ввод
1. Поместите курсор в текстовое поле (оно автоматически получает фокус при загрузке).
2. Начните вводить латиницей слог или слово — например, `ni`, `hao`, `zhong`, `hua`.
3. Как только введённая последовательность совпадёт с ключом в `mappingVariants`, под полем появится список кандидатов (иероглифов и слов).
4. Выберите нужный вариант:
   - **Клик мышью** по кандидату.
   - **Enter** — вставить выделенный (первый) кандидат.
   - **↑ / ↓** или **Tab** — перемещаться по списку (с предпросмотром в поле ввода).
   - **Escape** — отменить ввод, скрыть список кандидатов.

### Предпросмотр
При наведении курсора на кандидата в поле ввода отображается предпросмотр: латинский слог заменяется на выбранный иероглиф с подчёркиванием. Это позволяет оценить результат до подтверждения.

### Обратное преобразование (ㄌㄚㄊㄧㄋ于化)
Кнопка **«ㄌㄚㄊㄧㄋ于化»** (латиница → иероглифы) выполняет обратное преобразование: берёт текст из поля ввода, находит для каждого иероглифа его латинское чтение (по обратному словарю `reverseMap`) и выводит результат в блок «ㄌㄚㄊㄧㄋ的最后 (布可以)». Это позволяет получить пиньинь-запись уже набранного текста.

## Особенности раскладки

### Специальные символы
| Ввод | Результат |
|------|-----------|
| `` ` `` | пробел |
| `,` | запятая |
| `~` | идеографический пробел (U+3000) |
| `~~` | тильда `~` |
| `-` | длинное тире `—` |
| `--` | двойное тире `——` |
| `/` | каплевидная запятая `、` |
| `.` | азиатская точка `。` |
| `...` | многоточие `……` |
| `[` | открывающие скобки: `「『〈《` (циклический выбор) |
| `]` | закрывающие скобки: `」』〉》` (циклический выбор) |

### Чжуинь фухао (注音符號)
Клавиатура поддерживает ввод символов чжуинь фухао. Например:
- `z` → ㄗ, `zh` → ㄓ, `j` → ㄐ, `g` → ㄍ, `d` → ㄉ, `b` → ㄅ
- `i` → ㄧ, `u`/`w` → ㄨ, `v` → ㄩ
- `a` → ㄚ, `o` → ㄛ, `e` → ㄜ, `ai` → ㄞ, `ei` → ㄟ, `ao` → ㄠ, `ou` → ㄡ
- `an` → ㄢ, `en` → ㄣ, `ang` → ㄤ, `eng`/`ng` → ㄥ, `ong` → ㄨㄥ
- `er` → ㄦ

### Слоги и слова
Словарь `mappingVariants` содержит:
- **Однослоговые иероглифы**: `ni` → 你, `hao` → 好, `zhong` → 中, `hua` → 花/华/化/話, `guo` → 国, `ren` → 人, `min` → 民 и т.д.
- **Многосложные слова**: `zhongguo` → 中国, `zhonghua` → 中华, `hongweibing` → 红卫兵, `weida` → 伟大, `tongzhi` → 同志, `xiexie` → 谢谢, `shenme` → 什么, `dongfang` → 东方, `beijing` → 北京, `nanjing` → 南京, `shanghai` → 上海 и т.д.
- **Сложные термины**: `gongzhuyuan` → 共主院, `gongchandang` → 共産党, `guomindang` → 国民党, `makesizhuyi` → 马克思主义, `lieningzhuyi` → 列宁主义, `maozedongsixiang` → 毛泽东思想, `sanminzhuyi` → 三民主义 и т.д.

### Приоритет совпадений
При вводе используется **наибольшее совпадение**: если вы ввели `zhongguo`, система сначала проверит всё слово целиком, и только если такого ключа нет — разобьёт на более короткие. Это позволяет вводить как отдельные слоги, так и целые слова.

## Соответствие стандарту H-1.1

Клавиатура реализует **Первый стандарт бэйтайского языка Huawei-I.I (H-1.1)**. В стандарте описаны:

- **Фонетика**: чжуинь фухао и латинская запись (пиньинь), русское звучание.
- **Иероглифический минимум**: около 380 иероглифов с чтениями и значениями.
- **Грамматика**: порядок слов «обстоятельство времени/места + субъект + объект + глагол + частица», отсутствие рода и времени, частицы (的, 们, 吗, 了, 见, 完, 在, 都, 和, 或, 如果, 但是, 因为, 也, 被, 要, 为, 一下, 没有, 比 и др.).
- **Счётные слова**: 个 (для предметов), 次 (для действий).
- **Местоимения**: 私 (я), 你 (ты/вы), 她/他/它 (она/он/оно — по степени осознанности), 咱们 (мы с собеседником), 这 (это), 那 (то).
- **Вопросительные слова**: 谁 (кто), 什么 (что), 什候 (когда), 哪 (где), 如何 (как).
- **Лексика**: небесные тела, повседневность, образование, общество, политика, религия, природа, наука.

Клавиатура покрывает значительную часть этого словаря. Если в программе отсутствует какой-либо иероглиф — это техническая недоработка, о которой можно сообщить в комментариях.

## Технические детали

### Структура
- `huawen.html` — единственный файл приложения (HTML + CSS + JavaScript).
- `mappingVariants` — объект, где ключ — латинская запись, значение — массив вариантов (иероглифов/слов).
- `reverseMap` — обратный словарь, строится автоматически из `mappingVariants` для функции «ㄌㄚㄊㄧㄋ于化».
- Шрифт: `NotoSerifCJKtc-Medium.otf` (подключается через `@font-face`).

### Логика работы
1. При вводе текста в `textarea` отслеживается последняя введённая последовательность символов (`composing`).
2. Ищется наибольшее совпадение в `mappingVariants`.
3. Если совпадение найдено — показывается список кандидатов, включается режим предпросмотра.
4. При выборе кандидата латинский слог заменяется на иероглиф.
5. При отмене (Escape) или вводе символа, не входящего в словарь, режим предпросмотра выключается.

### Ограничения
- Нет поддержки тонов (их в языке нет).
- Нет поддержки больших текстов (буфер обмена и позиционирование курсора работают, но интерфейс не оптимизирован).
- Интерфейс на хуавэнь — требуется знание языка или метод проб и ошибок.
